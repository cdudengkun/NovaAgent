# 公司开发规范

## 日志规范
所有生产环境日志必须使用 INFO 级别以上。
DEBUG 级别日志禁止在生产环境输出。
异常必须记录完整堆栈，使用 log.error("msg", e)。
禁止使用 System.out.println 输出日志。

## 分支规范
主分支为 main，禁止直接 push。
功能开发使用 feature/xxx 分支。
发布使用 release/x.y.z 分支。
所有合并必须经过 Code Review。

## 接口规范
所有对外接口必须返回统一的 Result<T> 结构。
错误码必须使用枚举定义，禁止硬编码数字。
接口必须做参数校验，使用 @Valid 注解。
